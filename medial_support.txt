DataTracker - Network Data Usage Monitor

Short description:
Monitor real-time network speed, track per-app data usage, run speed tests, and set data limits with alerts on Windows.

Long description:
DataTracker is a lightweight Windows desktop application that provides real-time network monitoring, per-application data usage tracking, built-in speed testing, and configurable data limit notifications. It displays live download/upload speeds with a 5-minute speed history chart, breaks down data usage by day and month with app-level detail (including IPv4 and IPv6 connections), provides a peak hours heatmap to visualize usage patterns, and sends toast notifications when usage crosses warning or danger thresholds. Features a built-in speed test powered by Cloudflare to verify ISP speeds, measuring download, upload, and latency. Built with Tauri 2, React 19, and Rust for fast, native performance with minimal resource usage. Security is a priority: the app ships with a strict Content-Security-Policy and verified, signature-checked updates.
