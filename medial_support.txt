DataTracker - Network Data Usage Monitor

Short description:
Monitor real-time network speed, track per-app data usage, and set data limits with alerts on Windows.

Long description:
DataTracker is a lightweight Windows desktop application that provides real-time network monitoring, per-application data usage tracking, and configurable data limit notifications. It displays live download/upload speeds with a 5-minute speed history chart, breaks down data usage by day and month with app-level detail, and sends toast notifications when usage crosses warning or danger thresholds. Built with Tauri 2, React 19, and Rust for fast, native performance with minimal resource usage.
