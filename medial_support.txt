1. TITLE
Data Tracker - Real-Time Network & Data Usage Monitor

2. SHORT DESCRIPTION
Data Tracker shows your live download and upload speeds, tracks daily and monthly data usage per app, and alerts you before you hit your data limits - all in a clean Windows app.

3. LONG DESCRIPTION
Data Tracker is a lightweight Windows data usage monitor that keeps you in control of your internet connection. The Live Dashboard shows real-time download, upload and total speeds with a rolling 5-minute speed history chart. Daily and monthly history pages break down usage by app and by day, so you always know what is consuming your data. Set daily and monthly data limits with warning and danger thresholds, and Data Tracker will notify you and play a sound alert before you go over. It runs quietly in the system tray, starts with Windows if you want, and keeps your history for the retention period you choose. Built with Tauri, Data Tracker is fast, low on RAM, and updates itself automatically from the repository. It enforces a single running instance, so launching it again simply brings the existing window back to the front.
