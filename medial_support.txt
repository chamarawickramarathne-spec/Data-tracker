1. TITLE
Data Tracker - Real-Time Network & Data Usage Monitor

2. SHORT DESCRIPTION
Data Tracker shows your live download and upload speeds, tracks daily and monthly data usage per app, and alerts you before you hit your data limits - all in a clean Windows app.

3. LONG DESCRIPTION
Data Tracker is a lightweight Windows data usage monitor that keeps you in control of your internet connection. The Live Dashboard shows real-time download, upload and total speeds with a rolling 5-minute speed history chart that stays live the whole time the window is open - focused or not. Daily and monthly history pages break down usage by app and by day, and now include top-5 charts plus a per-app detail panel: click any application in your history to see its hourly or daily usage breakdown and download/upload totals. Set daily and monthly data limits with warning and danger thresholds, and Data Tracker will send you a Windows toast notification and play a sound alert the moment you cross them. Turn on the daily summary and it will notify you at a set time each day with your download, upload and total usage. It runs quietly in the system tray, starts with Windows if you want, and keeps your history for the retention period you choose. Built with Tauri, Data Tracker is fast, low on RAM, and updates itself automatically - the in-app update check uses GitHub's release feed directly, so it never hits API rate limits and needs no extra software. When a new version is ready it downloads, restarts itself and relaunches the new build with no manual steps. It enforces a single running instance, so launching it again simply brings the existing window back to the front.
